============================================================================================================
xs_volume_surprise -- CROSS-SECTIONAL volume surprise by decile/quintile, split by day sign
============================================================================================================
signal : surprise = today_volume / median(prior 20 sessions' volume)   [causal, unit-free]
rank   : percentile of surprise against EVERY OTHER SYMBOL on the same date
branch : UP  = own close-to-close return > 0 that day
         DOWN= own close-to-close return < 0 that day
outcome: next-day close-to-close (primary), cross-sectionally DEMEANED (raw minus
         that date's cross-sectional mean) so the market move is netted out
universe: individual equities; crypto and index/sector ETFs excluded (sensitivity run adds ETFs)
split  : TRAIN signal dates < 2025-01-01, TEST >= 2025-01-01.  Nothing is fit on either.
se     : CLUSTERED BY DATE everywhere.  t_naive shown only to size the lie.
